# UpdateKubernetesClusterAttributes

Provide one of: worker_count, control_plane_count (for scaling), or kubernetes_version (for upgrades). These are mutually exclusive operations.

| `control_plane_count`                                                                                                                                    | *Optional[int]*                                                                                                                                          | :heavy_minus_sign:                                                                                                                                       | Desired number of control plane nodes. Minimum 1. Mutually exclusive with worker_count and kubernetes_version.                                           |

Required when scaling from 0 workers. Ignored when scaling an existing deployment.                                           |
